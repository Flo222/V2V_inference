# V2V_inference 最终清爽版代码结构说明

## 1. 三层边界

- `opencood/models/baselines/`：五个基线自己的模型、融合、原生 payload 语义，回答“传什么”。
- `opencood/methods/arce/`：ARCE/C2MAB 的重要度、上下文、动作、reward 与优先级策略，回答“怎么选”。
- `opencood/communication/`：量化、分包、FEC、Markov、时延、恢复等公共通信机制，回答“怎么执行”。

## 2. models

```text
opencood/models/
├── baselines/
│   ├── where2comm/
│   ├── v2xvit/
│   ├── cosdh/
│   ├── rocooper/
│   └── coopdiff/
├── common/
│   ├── sub_modules/
│   └── fuse_modules/
├── upstream/
└── registry.py
```

`registry.py` 负责把旧 YAML 中的 `model.core_method` 映射到新的正式模块路径，因此现有 YAML 不需要因为目录重构而改名。

## 3. communication

```text
opencood/communication/
├── interface/                      # NativePayload/NativeMessage/Action/Result
├── transport/
│   ├── quantization/               # FP32/FP16/INT8/INT4
│   ├── packetization/              # byte stream + packet
│   ├── fec/                        # None/XOR/RaptorSim/RaptorQ
│   └── recovery/                   # zero-fill/interpolation/temporal cache
├── channel/                        # Markov/GE/loss/bandwidth/latency
├── pipeline/
└── metrics/
```

### 通信代码速查

| 功能 | 代码位置 |
|---|---|
| INT4/INT8/FP16 量化 | `opencood/communication/transport/quantization/` |
| 字节序列化/分包 | `opencood/communication/transport/packetization/` |
| XOR/RaptorQ 冗余 | `opencood/communication/transport/fec/` |
| Markov/丢包/带宽 | `opencood/communication/channel/` |
| 网络时延 | `opencood/communication/channel/latency_model.py` |
| Temporal Cache | `opencood/communication/transport/recovery/temporal_cache.py` |
| Zero Fill / 空间插值 | `opencood/communication/transport/recovery/` |
| 通信量统计 | `opencood/communication/metrics/` |

## 4. ARCE

```text
opencood/methods/arce/
├── arce_fixed_comm.py
├── arce_c2mab_comm.py
├── controller.py
├── priority_block_fec_transport.py
├── policies/
└── audit/
```

- 通用 INT4、RaptorQ、Temporal Cache 的底层算法不属于 ARCE，放在 `communication`。
- ARCE 负责选择量化等级、冗余率、重要度顺序、action 和 reward。
- `priority_block_fec_transport.py` 保存“重要信息优先获得冗余保护”的 ARCE 策略；真正的 RaptorQ codec 在公共 FEC 目录。

## 5. 最终数据流

```text
Baseline native feature/message
        ↓
NativePayload / NativeMessage
        ↓
ARCE context + importance + C2MAB
        ↓
CommunicationAction
        ↓
Quantization
        ↓
Byte Packetization
        ↓
FEC / RaptorQ
        ↓
Markov / Bandwidth / Loss / Latency
        ↓
FEC Decode
        ↓
Temporal Cache / Interpolation / Zero Fill
        ↓
Recovered Payload
        ↓
Baseline Fusion
        ↓
Detection / AP
```
